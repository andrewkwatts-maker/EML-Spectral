Mathematical Concepts

1. The EML Sheffer operator (recap)

EML-Spectral is built on the EML Sheffer operator from eml-math. A Sheffer operator is a single binary operation from which all other operations in a system can be derived. For Boolean logic this is NAND; for continuous real-valued mathematics, Odrzywolek (2026) showed that the role is played by:

eml(x, y) = exp(x) − ln(y)

From eml and the constant 1, every elementary function (addition, multiplication, sin, cos, π, e) can be expressed as a finite composition. EML-Spectral never re-implements these — it imports EMLPoint directly from eml-math and layers algebraic, geometric, and dynamical structure on top.

2. EMLPair as a two-real complex

Complex numbers ordinarily require either a primitive complex type or two reals plus a sign convention. EMLPair stores two EMLState objects in phase relationship and performs all complex arithmetic without ever invoking Python's complex:

from eml_spectral import EMLPair

z1 = EMLPair.from_values(3.0, 4.0)    # 3 + 4i
z2 = EMLPair.from_values(1.0, 2.0)    # 1 + 2i
z3 = z1 * z2                            # -5 + 10i, all reals
print(z1.modulus, z1.argument)          # 5.0, atan2(4, 3)

The four canonical rotations {×1, ×i, ×−1, ×−i} are the frames() method — they all share an identical Euclidean delta, mirroring the U(1) phase symmetry of complex numbers.

3. Spectral flow Φ(n, ρ, θ) (Axiom 3)

The spectral flow Φ is the canonical time-evolution of an EML state. It is parameterised by three quantities:

  • n — integer flip count (number of completed Mirror-Pulses)
  • ρ — tension density |T| (continuous, conserved along the orbit)
  • θ — phase ∈ [0, 2π)

Each Mirror-Pulse advances (x, y) → (|y|, exp(x) − ln|y|); Φ wraps the trajectory in (n, ρ, θ) coordinates and exposes it through spectral_flow().

The y-safe guard (Axiom 8)

Because ln(y) is undefined for y ≤ 0, the operator silently substitutes |y|. This frame-shift guard keeps the trajectory in the real domain without loss of information — the sign of y is recovered from the phase θ.

Racetrack fixed points (Axiom 6)

A racetrack is a periodic orbit of the spectral flow. racetrack_fixed_point() locates the periodic point reached from a given seed; the canonical seed list G2_SEEDS is selected so that the resulting orbit lies inside a G₂ symmetric subspace of the EML phase space.

The (b₃/24)·χeff = 144 invariant (Axiom 4)

Along every conserved orbit, the topological invariant

I = (b₃ / 24) · χeff = 144

holds exactly. Here b₃ is the third Betti number of the orbit's parameter manifold and χeff is its effective Euler characteristic. The function topology_invariant() evaluates this directly.

4. Lorentz invariance

The Minkowski delta of an EML coordinate pair

ΔM(x, y) = √|exp(2x) − (c · ln y)²|

is invariant under Lorentz boosts. A boost by rapidity φ is a hyperbolic rotation in the (t, s) = (exp(x), ln|y|) plane:

t' = t · cosh(φ) − (s/c) · sinh(φ)
s' = s · cosh(φ) − t · c · sinh(φ)

Rapidities are additive: boost(boost(p, φ₁), φ₂) = boost(p, φ₁ + φ₂). The functional API spacetime.boost implements this directly; FourMomentum.boost applies the same transformation in 3+1D, with rest mass conserved to numerical precision.

5. The exceptional ladder G₂ → F₄ → E₆ → E₇ → E₈

The exceptional simple Lie algebras have dimensions:

AlgebraDimensionRole in EML-Spectral
G₂14automorphism group of the octonions; G2_SEEDS
F₄52automorphism group of J₃(O) (exceptional Jordan algebra)
E₆78arises in heterotic compactifications
E₇133fundamental rep is 56-dim — E7_56 + FreudenthalTripleSystem
E₈248adjoint rep — E8_248; heterotic gauge group E8xE8

The Freudenthal magic square arranges these algebras in a 4×4 grid indexed by the four normed division algebras (R, C, H, O). The exceptional Jordan algebra J₃(O) — 3×3 Hermitian matrices over the octonions — sits at one corner. Its automorphism group is F₄; its conformal group is E₆; the Freudenthal triple over it gives the 56-dim representation of E₇, exposed via FreudenthalTripleSystem.

6. E₈ and Leech lattices

Two extraordinary lattices appear in EML-Spectral:

  • E₈ — 8-dimensional, 240 minimal vectors at norm √2. Densest sphere packing in 8D (Viazovska, 2016).
  • Leech — 24-dimensional, 196560 minimal vectors at norm 2. Densest sphere packing in 24D (Cohn et al., 2017).

The kissing numbers (240 in 8D, 196560 in 24D) are tight: they are exactly the maximum number of unit spheres that can simultaneously touch a central one. e8_lattice_points and leech_lattice_points enumerate vectors of these lattices as EMLNDVectors.

7. Schwarzschild and FLRW metrics

Two named factories cover the most-used GR metrics. The Schwarzschild line element in EML coordinates (with r = exp(x)) is:

ds² = −(1 − rs/r) dt² + (1 − rs/r)−1 dr² + r² dΩ²

Christoffel symbols for Schwarzschild have closed-form expressions; when the Rust extension is installed, MetricTensor.christoffel dispatches to the analytic implementation. The FLRW metric uses a user-supplied scale factor a(t):

ds² = −dt² + a(t)² (dr² + r² dΩ²)

The other six factories cover Calabi–Yau₃, Klebanov–Strassler, Heterotic E₈×E₈, AdS₅×S⁵, the G₂-holonomy cone, and flat Minkowski. All return a MetricTensor with the same uniform interface (ds2, proper_time, is_curved, christoffel).
