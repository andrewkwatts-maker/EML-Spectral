Getting Started Guide

1. Installation

EML-Spectral is a pure-Python package built on top of eml-math. The base install pulls in only eml-math as a runtime dependency.

pip install eml-spectral         # core library
pip install eml-spectral[ext]    # + NumPy and SymPy
Pre-built wheels target Python 3.10–3.13 on Windows, macOS, and Linux. The Rust extension eml_spectral_core is bundled when available; if not, every operation has a pure-Python fallback.

2. Hello, Spectral

The single-line tour: build a two-real complex pair, drive the spectral flow, inspect the resulting state.

from eml_spectral import EMLPair, spectral_flow

z = EMLPair.from_values(3.0, 4.0)
print(z.modulus, z.argument)        # 5.0,  atan2(4, 3)

state = spectral_flow(rho=1.0, n=4, theta=0.0)
print(state.rho, state.flip_count, state.phase)

All EMLPair arithmetic is real-valued: there is no Python complex anywhere in the call graph.

3. Spacetime — boosts and Lorentz invariance

Use the functional spacetime namespace to apply Lorentz boosts on EMLPoints. The Minkowski delta ΔM is invariant by construction.

from eml_math import EMLPoint
from eml_spectral import spacetime

p  = EMLPoint(2.0, 2.71828)
print(spacetime.light_cone_type(p))               # "timelike"
print(spacetime.rapidity(p))                       # atanh(1/e^2)

p2 = spacetime.boost(p, phi=0.693)
print(abs(spacetime.minkowski_delta(p) - spacetime.minkowski_delta(p2)) < 1e-10)
# True — Δ_M is conserved

For 3+1D vectors and four-momenta, use the MinkowskiFourVector and FourMomentum classes. Both expose .boost(phi) and preserve the rest mass.

4. General relativity — Schwarzschild

Build a MetricTensor via one of eight named factories. Christoffel symbols are computed numerically by default, with an analytic Rust fast path for Schwarzschild.

from eml_math import EMLPoint
from eml_spectral import MetricTensor, EMLState

g = MetricTensor.schwarzschild(rs=2.0)
p = EMLPoint(3.0, 1.0)            # r = exp(3) ≈ 20 ≫ rs=2

print(g.is_curved(p))                  # True
print(g.christoffel(0, 0, 1, p))      # Γ⁰_{01}

state = EMLState.from_point(p)
for _ in range(50):
    state = state.geodesic_step(g, dtau=0.005)

FLRW cosmology and the other six factories follow the same pattern — just swap the constructor.

5. Clifford rotor in 2D

EMLMultivector implements the full geometric product. A rotor is a unit even-grade element; sandwiching v → R v R̃ rotates v.

from eml_math import EMLPoint
from eml_spectral import EMLMultivector
import math

def vec2(a, b, sig=(1, 1)):
    comps = [EMLPoint(0.0, 1.0)] * 4
    comps[1] = EMLPoint(a, 1.0)
    comps[2] = EMLPoint(b, 1.0)
    return EMLMultivector(comps, signature=sig)

v = vec2(3.0, 4.0)
print(v.quadratic())                                # 25

R = v.rotor(math.pi / 4, plane=(0, 1))
v_rot = v.rotate(R)
print(abs(v_rot.quadratic() - v.quadratic()) < 1e-8)   # True

6. Octonions — the Fano product

Octonion multiplication is non-associative and non-commutative, but its norm is multiplicative. The product is encoded by the Fano plane: e1 e2 = e4, e2 e3 = e5, etc.

from eml_spectral import basis_octonion

e1, e2, e4 = basis_octonion(1), basis_octonion(2), basis_octonion(4)

print((e1 * e2).component(4))     # 1.0
print((e2 * e1).component(4))     # -1.0  (anticommutative)

# Multiplicative norm: |a b| = |a| |b|
print(abs((e1 * e2).norm() - e1.norm() * e2.norm()) < 1e-9)  # True

7. The exceptional ladder G₂ → F₄ → E₆ → E₇ → E₈

The exceptional Lie algebras form a tower whose dimensions are 14, 52, 78, 133, 248. EML-Spectral exposes the two largest representations directly, plus the Freudenthal triple system that connects them.

from eml_spectral import FreudenthalTripleSystem, E7_56, E8_248, E8xE8

F = FreudenthalTripleSystem()
print(F.dim)                # 56  (fundamental of E7)

e7 = E7_56()
e8 = E8_248()
print(e7.dim, e8.dim)       # 56, 248

heterotic = E8xE8()
print(heterotic.dim)        # 496

8. E₈ and Leech lattices

The E₈ lattice has 240 minimal vectors at norm √2 (the kissing number in 8 dimensions). The Leech lattice in 24 dimensions has kissing number 196560 and gives the densest known sphere packing in that dimension.

from eml_spectral import e8_lattice_points, leech_lattice_points

roots = e8_lattice_points(n=240)         # up to 240 root vectors
print(len(roots))

leech = leech_lattice_points(n=10)         # first 10 Leech vectors
print([v.euclidean_norm() for v in leech[:3]])

9. Spectral flow and racetrack fixed points

The flow Φ(n, ρ, θ) drives a Mirror-Pulse trajectory at fixed tension density. Periodic orbits — "racetracks" — are the fixed points of this flow under Axiom 6, and the topological invariant (b₃ / 24) · χeff equals 144 along every conserved orbit.

from eml_spectral import (
    spectral_flow, racetrack_fixed_point, topology_invariant, G2_SEEDS,
)

state = spectral_flow(rho=1.0, n=4, theta=0.0)
print(state.rho, state.flip_count)

fp = racetrack_fixed_point(seed=G2_SEEDS[0])
print(fp)                                  # the periodic fixed point

print(topology_invariant())                # 144

10. Optional Rust acceleration

When the eml_spectral_core extension is installed, batch operations dispatch to a Rayon-parallel Rust backend. Speed-ups are roughly 3× for boosts, 2× for octonion products, and up to 9× for low-dimensional Clifford products.

from eml_spectral import eml_spectral_core
import math

N = 10_000
points = [(1.0, math.e)] * N
phis   = [0.5] * N

boosted = eml_spectral_core.boost_n(points, phis, c=1.0)        # parallel
gammas  = eml_spectral_core.christoffel_batch_n(points, 0, 0, 1, rs=2.0)
The Rust extension is optional: if it is not installed, every batch helper falls back to a pure-Python loop. Production code can rely on the fallback.

11. Optional C API

The standalone library libeml_spectral exposes the hot-path operations to C, C++, and any language with FFI. Build with cargo build --release -p eml_spectral_c_api, then link against -leml_spectral.

// In your C program:
#include "eml_spectral.h"
#include <stdio.h>

int main(void) {
    double ox, oy;
    eml_spectral_boost(1.0, 2.718, 0.5, 1.0, &ox, &oy);

    double a[8] = {0,1,0,0,0,0,0,0};
    double b[8] = {0,0,1,0,0,0,0,0};
    double r[8];
    eml_spectral_octonion_mul(a, b, r);   // r[4] == 1.0
    printf("e1*e2 = e%d\n", 4);
    return 0;
}
# Compile
gcc main.c -Ic_api -Ltarget/release -leml_spectral -lm -o main
g++ main.cpp -Ic_api -Ltarget/release -leml_spectral -lm -o main
