EML-Spectral

Clifford algebras · octonions · exceptional algebras · GR metrics · Lorentz ops · spectral flow Φ

Φ(n, ρ, θ)  ·  (b₃/24)·χeff = 144

Built on eml-math. Zero runtime dependencies. Optional Rust + C extensions for batch acceleration of Clifford products, octonion multiplication, Lorentz boosts, and Christoffel symbols.

Get Started API Reference Concepts

Install

pip install eml-spectral
pip install eml-spectral[ext]   # adds NumPy + SymPy acceleration

Five-line tour

from eml_spectral import EMLPair, MetricTensor, spectral_flow

z       = EMLPair.from_values(3.0, 4.0)            # two-real complex
g       = MetricTensor.schwarzschild(rs=2.0)         # GR metric
state   = spectral_flow(rho=1.0, n=4, theta=0.0)    # Φ(n, ρ, θ)
print(z.modulus, g.is_curved(z.real_state), state)

What's inside

Algebras

EMLPair, EMLMultivector (Clifford), Octonion (Fano product), FreudenthalTripleSystem, E7_56, E8_248, E8xE8 — the full G₂ → F₄ → E₆ → E₇ → E₈ ladder.

Spacetime

MinkowskiFourVector, FourMomentum, plus the functional spacetime namespace with boost, rapidity, minkowski_delta, light_cone_type, and light_cone_coordinates.

Metrics

MetricTensor with eight named factories: flat, Schwarzschild, FLRW, Calabi–Yau₃, Klebanov–Strassler, Heterotic E₈×E₈, AdS₅×S⁵, and G₂-holonomy.

Lattices

EMLNDVector, e8_lattice_points, leech_lattice_points, plus Planck-scale tools planck_delta, lattice_distance, is_lattice_neighbor.

Spectral dynamics

spectral_flow, racetrack_fixed_point, topology_invariant, EMLState, simulate_pulses, verify_conservation — the Φ(n, ρ, θ) flow with the (b₃/24)·χeff=144 invariant.

Built on eml-math

Reuses EMLPoint, the 36 elementary operators, and the Mirror-Pulse engine from eml-math. No duplication, no shim layers.

Optional acceleration

Rust extension — eml_spectral_core: batch functions boost_n, octonion_mul_n, geometric_product_n, christoffel_batch_n. Built with PyO3 + Rayon, used automatically when the wheel is installed.
C API — libeml_spectral: standalone static + shared library with header eml_spectral.h. No Python required — link from C, C++, or any language with FFI.
