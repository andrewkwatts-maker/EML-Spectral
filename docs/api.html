API Reference

All public symbols listed below are importable from eml_spectral directly. Submodules (eml_spectral.spacetime, eml_spectral.exceptional, etc.) are also supported for fine-grained access.

Algebras

EMLPair

from eml_spectral import EMLPair

Two-real replacement for complex. Stores real and imaginary EMLState objects so that all arithmetic stays in the EML tree representation.

Method / PropertyDescription
EMLPair(real_state, imag_state)Construct from two EMLState objects.
EMLPair.from_values(r, i)Construct from a scalar real/imag pair.
EMLPair.from_polar(r, theta)Polar form r·e^(iθ).
.real_tension, .imag_tensionComponent tensions (floats).
.modulus|z| = √(re² + im²).
.argumentPhase θ = atan2(im, re).
.conjugate()Complex conjugate.
.rotate_phase(angle)Rotate by angle radians.
.frames()The four canonical rotations (×1, ×i, ×−1, ×−i).
+, -, *, /Complex arithmetic via EMLPair operators.
 
from eml_spectral import EMLPair
z = EMLPair.from_values(3.0, 4.0)
print(z.modulus)        # 5.0
print(z.argument)       # atan2(4, 3)

EMLMultivector

from eml_spectral import EMLMultivector

Clifford / geometric algebra multivector with full geometric product ab = a·b + a∧b, grade projection, reverse, and rotors. Configurable signature.

MethodDescription
EMLMultivector(components, signature)Build from a list of EMLPoint components.
* (geometric product)Full Clifford product. Rust-accelerated for n≤8 dims.
.quadratic()Scalar part of a × reverse(a).
.reverse()Grade-reversed multivector.
.rotor(angle, plane)Build a rotor exp(angle × B/2) in plane = (i, j).
.rotate(R)Apply rotor sandwich R × v × reverse(R).
EMLMultivector.spacetime(components)Convenience factory for Cl(1, 3).

Octonion

from eml_spectral import Octonion, basis_octonion

Eight-dimensional non-associative division algebra. Multiplication uses the Fano-plane lookup table.

MethodDescription
Octonion(c0, c1, …, c7)Construct from eight real components.
basis_octonion(i)i-th basis octonion (i ∈ 0..7).
* (Fano product)Non-associative multiplication. Rust-accelerated.
.norm()√∑ci². Multiplicative.
.conjugate()Negate the imaginary components.
.component(i)Read the i-th coefficient.
.to_ndvector()Convert to an EMLNDVector.
 
from eml_spectral import basis_octonion
e1, e2 = basis_octonion(1), basis_octonion(2)
print((e1 * e2).component(4))   # 1.0  (Fano: e1*e2 = e4)
print((e2 * e1).component(4))   # -1.0 (anticommutative)

FreudenthalTripleSystem

from eml_spectral import FreudenthalTripleSystem

Implements the Freudenthal triple F = (J, φ, q) over the exceptional Jordan algebra J₃(O). Underpins E₇.

from eml_spectral import FreudenthalTripleSystem
F = FreudenthalTripleSystem()

spacetime (functional namespace)

from eml_spectral import spacetime

Stateless functions operating on EMLPoints.

FunctionDescription
spacetime.minkowski_delta(p, signature, c)ΔM = √|exp(2x) − (c·ln y)²|.
spacetime.euclidean_delta(p)√(exp(2x) + (ln y)²).
spacetime.rapidity(p)atanh(ln(y) / exp(x)). Raises for spacelike.
spacetime.boost(p, phi, c)Lorentz boost preserving ΔM.
spacetime.light_cone_type(p, c)"timelike" / "spacelike" / "lightlike".
spacetime.light_cone_coordinates(p, c)Null coordinates (t+s, t−s).
 
from eml_math import EMLPoint
from eml_spectral import spacetime

p = EMLPoint(2.0, 2.71828)
print(spacetime.light_cone_type(p))                          # "timelike"
print(spacetime.minkowski_delta(spacetime.boost(p, 0.5)))   # invariant

MetricTensor.calabi_yau_3(kahler_potential)Kähler metric on a CY 3-fold.

MetricTensor.heterotic_e8x8(radius=1.0)E₈×E₈ heterotic compactification.

MetricTensor.g2_holonomy()Bryant–Salamon G₂-holonomy cone.

Spectral dynamics

spectral_flow

spectral_flow(rho, n, theta) → EMLState

The flow Φ(n, ρ, θ) of Axiom 3. Drives the Mirror-Pulse trajectory at fixed tension density.

from eml_spectral import spectral_flow
state = spectral_flow(rho=1.0, n=4, theta=0.0)
print(state.rho, state.flip_count, state.phase)

racetrack_fixed_point

racetrack_fixed_point(seed, max_iter=10000, tol=1e-9) → EMLState | None

Locate the periodic fixed point of the racetrack flow (Axiom 6) starting from seed.

topology_invariant

topology_invariant(b3=24, chi_eff=144) → float

The topological invariant (b₃ / 24) · χeff. Returns 144 by Axiom 4.

G2_SEEDS

G2_SEEDS: tuple — canonical seed values for the G₂ orbit used by racetrack_fixed_point.

EMLState

from eml_spectral import EMLState

Full Φ(n, ρ, θ) state: an EMLPoint plus integer flip count n and phase θ.

MethodDescription
EMLState(point, n=0, theta=0.0)Construct.
EMLState.from_point(point, n, theta)Factory classmethod.
.rhoTension density |T|.
.flip_countNumber of completed Mirror-Pulses.
.phasePhase θ ∈ [0, 2π).
.mirror_pulse()One pulse step.
.three_one_flip()4-pulse 3+1 cycle.
.geodesic_step(metric, dtau)Euler geodesic step under a MetricTensor.

simulate_pulses

simulate_pulses(state, n_pulses) → list[EMLState]

Run n_pulses Mirror-Pulses and return the trajectory. Aliased as iterate.

simulate_flips

simulate_flips(state, n_flips) → list[EMLState]

Run n_flips 3+1 cycles (4 pulses each).

quantized_trajectory

quantized_trajectory(state, n, D) → list[EMLState]

Discrete-mode trajectory at quantization step D.

tension_series / rho_series / phase_series

tension_series(traj) → list[float] (and similarly for rho_series, phase_series) — extract scalar series from a trajectory.

verify_conservation

verify_conservation(traj, tol=1e-9) → bool

Check Axiom 10: T + ln(y) = exp(x) at every step.

frame_shift_count

frame_shift_count(traj) → int

Number of times the Axiom-8 frame-shift guard fired along the trajectory.

find_resonance_bands

find_resonance_bands(traj, tol=1e-3) → list[tuple]

Detect bands where consecutive states satisfy Axiom 14 (matching tension ratios).
